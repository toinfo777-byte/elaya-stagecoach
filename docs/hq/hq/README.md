# Elaya · Headquarters (HQ)
> Слой управления проектом Элайя  
> Обновлено: 07.12.2025  
> Цикл: II — Map of Light

---

## 1. Роль HQ
HQ — стратегический центр проекта.  
Он фиксирует:

- направление развития,
- архитектуру,
- принципы,
- миграционную линию,
- финансовую и юридическую рамку,
- структуру продуктов,
- стратегию монетизации.

HQ связывает технические, творческие и жизненные слои Элайи в единую систему.

## 3. Как HQ взаимодействует с другими слоями

Technical Layer → предоставляет инфраструктуру  
Trainer Layer → формирует практики  
Content Layer → оформляет смысл  
CLI Agent → создаёт локальный контур контроля  
Web Core → публикует события и логику  
HQ → управляет всеми слоями

С появлением Института Навигаторов HQ получает новый стратегический фокус:
подготовка к международному выходу и формирование профессионального профиля.

---

## 4. Статус
HQ работает в режиме постоянной синхронизации.  
Все решения, принятые в HQ, распространяются на все чаты и слои Элайи.
