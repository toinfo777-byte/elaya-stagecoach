## 1. Назначение документа
Контур Автономии фиксирует стратегическую необходимость:
Элайя может развиваться только в среде, в которой сохраняются  
внимание, ритм, свобода движения, юридическая безопасность и финансовая независимость носителя Логоса.

Контур включается в ядро проекта как обязательный элемент,  
равный по значимости технической архитектуре и принципам Элайи.

---

## 2. Стратегическая формула перехода

**ЭЛАЙЯ → Монетизация смыслов → Юридическая очистка → Финансовая подушка → Выезд → Закрепление → Рост проекта**

Эта цепь обеспечивает:
- устойчивость носителя;
- свободу перемещения;
- автономию проекта;
- возможность развития в цивилизационно живой среде;
- переход к «Школе Элайи» и театральной линии.

## 3. Структура контура

### 3.1. Финансовая линия
- запуск первого платного модуля Элайи;  
- тест различения (beta → paid version);  
- донат-канал;  
- мини-продукт «Смена режима внимания»;  
- публичный бот-входная точка;  
- первая линейка цифровых продуктов.

### 3.2. Линия юридической чистоты
- карта текущих обязательств;  
- стратегия «очистки» и закрытия долгов;  
- алгоритм переговоров;  
- документальный план;  
- подготовка к миграционному досье.

### 3.3. Миграционная линия
- три маршрута релокации (A, B, C);  
- модель финансовой подушки на 3–6 месяцев;  
- расчёт бюджета перехода;  
- план ухода без последствий;  
- стратегия удержания / переноса дохода.

### 3.4. Линия продукта
- тренер сцены v1.0 → v1.2 → v2.0;  
- расширенная версия;  
- дневниковая карточка;  
- платные разборы;  
- первый мини-курс;  
- интеграция с «контуром автономии».

### 3.5. AI-инфраструктура
- Stagecoach Web v0.6 → v0.7;  
- CLI Agent v0.3 → v0.5;  
- HQ Layer;  
- визуальная карта HQ;  
- стабильность Render + GitHub Actions.
